# Premade assets & licenses: **required for submission** (rules 3.3–3.6)

Anything the team **didn't make during the jam**: sprites, models, sounds, music, fonts, shaders, code libraries, Unity packages beyond the defaults, even if modified.
Declare in **all 5 categories** (Görsel / Ses / Kod / Metin / Diğer). Undeclared premade asset = disqualification.
Crediting the source does not replace having permission. Only use assets whose license allows it.

✅ Safe sources: CC0 (Kenney.nl, OpenGameArt CC0, freesound CC0), Google Fonts (OFL), and things you made yourself during the jam.
⚠️ **Unity Asset Store** packages may be used, but their license does **not** allow putting the raw files in a public repo. Put them in `Game/Assets/ThirdParty_NoRedistribute/` (git-ignored) and fill in the "not in repo" section.
