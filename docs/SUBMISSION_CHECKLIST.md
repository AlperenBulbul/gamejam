# Submission checklist (Sunday 18 Oct)

Submit at **https://game.ktimo.com.tr/jam/teslim**. The team representative logs in with the team name + 6-character code (keep the code private).
**Target: 16:00. Hard limit: the upload must have *started on the server* before 18:00.** Git help from the organizers ends at **12:00**.

## Build
- [ ] All teammates' work is pulled; `main` is pushed
- [ ] `Jam > Build Windows (zip)` was run from a **clean, pushed** commit (no "uncommitted changes" warning; `BUILD_INFO.txt` shows the commit)
- [ ] ZIP unzipped and run on a **different PC** that doesn't have Unity installed
- [ ] Played start → end with no crash; restart works; Esc/quit works
- [ ] ZIP ≤ 10 GB
- [ ] (Web build only) link opens in a desktop browser **without logging in**

## Video
- [ ] ≤ **1 minute**, gameplay or trailer, **MP4 or AVI**, ≤ 5 GB
- [ ] Uploaded as a file (not a link); opened and checked for sound/picture

## Repo
- [ ] Repo is **PUBLIC**. Open the link in a private/incognito window to check (private = disqualified, whatever the score)
- [ ] No passwords / keys / personal data in the repo
- [ ] No non-redistributable assets in the repo; how to get them is documented in ASSET_CREDITS.md
- [ ] README has platform, how to start, goal, controls, known issues

## Form contents (rule 5.2)
- [ ] Game name + short description
- [ ] Platform: Windows (or web)
- [ ] ZIP uploaded
- [ ] Video uploaded
- [ ] Public Git repo HTTPS link
- [ ] Install/run/controls instructions (copy from README "How to play")
- [ ] Premade assets: all 5 categories answered (from `ASSET_CREDITS.md`)
- [ ] AI: all 5 categories answered with tool, purpose, where used (from `AI_LOG.md`)
- [ ] Accept submission terms + current rulebook version
- [ ] All teammates know and agree to the non-commercial usage license (rule 9)

## After uploading

- [ ] Don't push changes that make the repo differ from the submitted build after 18:00
- [ ] Presentation ready: 3 min total, video plays in the background while we talk, no Q&A
